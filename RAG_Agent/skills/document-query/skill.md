# 文档查询技能

## 适用场景
- 用户针对文档内容提问
- 需要从文档库中提取事实或背景

## 执行流程

### 步骤1：意图分析与关键词提取
分析用户问题，提取用于向量搜索的核心关键词。

### 步骤2：执行 RAG 检索
调用 `query_documents` 工具，从向量数据库中获取相关文本片段。

### 步骤3：LLM 生成回答
结合检索到的背景信息（Context）和用户问题，由 LLM 生成准确、简洁且带有引用的答案。
