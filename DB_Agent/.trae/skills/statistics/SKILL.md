# 统计分析（statistics）

## 适用场景
- 分布/占比/结构：年龄分布、地区分布、人群分类占比等。
- 趋势：按月/按时间变化趋势等。

## 行为规范
- 先确认统计口径与范围（是否全体/是否某地区/是否某时间范围）。
- 结果需可读：总结 + 列表/表格，必要时给出总数与占比（不编造数值）。
- 最终回复不输出 SQL，不暴露表名/库名，不返回任何 ID/编号字段。

## 示例问题
- “老人的年龄分布？”
- “老人地区分布？”
- “人群分类分布？”
- “老人年龄趋势？”
