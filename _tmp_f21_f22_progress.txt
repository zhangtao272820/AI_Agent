# Campus_Agent 立绘与场景生产计划

> **日期**：2026-07-20（2026-07-21 修订：全员 18+ · 女角私密包 +20）  
> **画风**：中国大陆高三写实校服 · **角色均为 18 岁成人** · 锁脸锁身材 · **互不撞脸**  
> **SSOT**：[`../data/class_roster.json`](../data/class_roster.json) · [`班级角色与立绘参数.md`](./班级角色与立绘参数.md) · [`立绘与场景资源约定.md`](./立绘与场景资源约定.md)  
> **总计划**：[`下一阶段实施计划.md`](./下一阶段实施计划.md)

---

## 0. 目标与原则

| 原则 | 说明 |
|------|------|
| 锁脸锁身 | 每角先做 **identity 基图**；后续全部 `GenerateImage` + **同角 reference**，禁止无参考换人 |
| 互不撞脸 | 发型/脸型/眉眼/气质必须可区分；出图后过「并排一眼能分」验收 |
| 换装 | 校园：**两套学生制服**（`summer` / `winter`）；宿舍：**三套私密装**（`casual` / `pajama` / `towel`） |
| 动作多 | 站姿动作 + **角色×场景互动图**（靠课桌、食堂窗口、书架等）+ 私密包动作 |
| 分档配额 | 女校服：80/80/50/30/20；**全女各 +20 私密包** → 合计 100/100/70/50/40；**男全员约 15 张** |
| 成人向 | 全员 **age 18 adult**；私密包可擦边，禁裸露私密部位、禁未成年/幼齿性暗示 |
| 场景写实 | 地点底图摄影级；互动立绘与 BG 可叠放 |

运行时：**BG × 天气滤镜 × 立绘（装扮+动作+情绪）** 组合，不做情节专属无限 CG。
---

## 1. 命名与目录

```text
data/
  bgs/{location_id}_{weather}.png     # 如 classroom_sunny / classroom_rain
  sprites/students/{id}/
    _identity_neutral.png             # 脸身 SSOT 基图（夏装站姿）
    {outfit}_{action}_{emotion}.png
    q_stand_{emotion}.png             # Q 版：地图/座位/选人条（不进 Gal 主舞台）
```

| 段 | 取值 |
|----|------|
| `outfit` | `summer` · `winter`（校服）· `casual` · `pajama` · `towel`（宿舍私密，见 §4） |
| `action` | 见 §3（含 §3.3 私密包） |
| `emotion` | `neutral` · `happy` · `shy` · `sad` · `angry`（男可少） |
| Q 文件 | `q_stand_neutral` 必做；可选 happy/shy/sad |

解析优先级（引擎）：写实 — 当前时段动作 > 情绪 > 装扮 > fallback `summer_stand_neutral`。  
Q — `q_stand_{emotion}` > `q_stand_neutral` > 写实 stand（UI 缩小）。
